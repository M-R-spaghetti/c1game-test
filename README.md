# Circus Overflow

A small Godot 4.7 vertical slice combining original GPT Image 2.5 artwork with deterministic 2D gameplay.

Miro has eight-frame walking strips for up, down, and sideways movement. Madame
Tock is an interactive NPC with four reactions unlocked by repeated conversations.

## Run

```bash
godot --path .
```

Move with WASD or arrow keys. Press E or Space near a glowing hotspot. Escape closes dialogue.

Art-production rules and the sources behind them are recorded in `docs/GPT_IMAGE_2_5_WORKFLOW.md`.
